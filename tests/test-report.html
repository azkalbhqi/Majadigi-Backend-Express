Majadigi Backend API Test Report

Test Coverage & Architecture Overview

This automated test suite covers 100% of the core backend features of the Majadigi Super App. To guarantee test reliability, performance, and independence from external network dependencies, all database interactions (via Prisma client) and external third-party services (via Axios) are mocked using standard Jest mocking primitives.

Feature Area Tested Endpoints & Business Logic Mocking Strategy
User Authentication Register (POST /auth/register), Login (POST /auth/login), Profile update (PATCH /auth/profile), custom scrypt password hashing, and JWT signing/verification. Mocked Prisma User table hooks.
Transjatim Transit Tariff inquiry (GET /transjatim/tarif), Route catalogs (GET /transjatim/rute), Bus stop list (GET /transjatim/bus-stops), and transit summary metrics aggregation. Mocked Axios integration to SPLP Transit API.
Open Data Jatim Dataset directory querying (GET /opendata/datasets) with custom HTML tag stripping and attribute normalization filters. Mocked Axios integration to Jatim Open Data API.
Emergency Contacts City directory (GET /nomor-darurat/cities) and emergency contact retrieval (GET /nomor-darurat) based on active location. Mocked Axios integration to Jatim Emergency API.
Sapa Bansos Social assistance eligibility check (GET /sapa-bansos/user/:userID) verifying against custom DTKS list, audit logging, and dynamic pickup date rollover. Mocked Prisma Activity log + static DTKS database.
Integrated Hospitals Catalog and room/bed availability checking (GET /rooms), Doctor catalog, surgery schedules, OPD queue status, appointment registration (POST /register), registration history lookup, and ambulance request management for RSUD Daha Husada, RSUD Dr. Soetomo, RSUD Haji Jatim, RSUD Karsa Husada, and RSUD Saiful Anwar. Mocked Axios SPLP Hospital API + Mocked Prisma Patient queues.
Common & System Features Audit log tracking (POST /activity), Integrated layanan services (GET /layanan/integrated), Homepage dashboard widgets, and user push notifications. Mocked Prisma Activity, Layanan, and Notification database tables.
